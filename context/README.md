# Context index

This folder is the project's living memory. It exists so any new coding agent (or Jatin) can pick up the work without the original conversation. **Keep it updated whenever you change anything.**

Last reviewed: 2026-11-01

| File | What it holds | Update when |
|---|---|---|
| [agent-onboarding.md](agent-onboarding.md) | Start here. How a new agent gets oriented, plus the upkeep rule | The onboarding process changes |
| [architecture.md](architecture.md) | File map, data flow, how sections are built | Files, components or structure change |
| [design-direction.md](design-direction.md) | Design language, tokens, sizes, motion, cursor, what was cut | Any visual rule changes |
| [components.md](components.md) | Detailed spec of each component and section | A component changes |
| [content.md](content.md) | Current copy, facts Jatin gave, placeholders | Copy or facts change |
| [tasks.md](tasks.md) | Ongoing, pending input, on hold, rejected, done | Any task status changes |
| [decisions.md](decisions.md) | Dated decision log with reasons | A choice is made or reversed |
| [references.md](references.md) | Inspiration sites and what to take or avoid | A new reference is shared |
| [changelog.md](changelog.md) | One line per session | End of every session |
